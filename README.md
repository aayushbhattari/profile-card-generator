#  Profile Card Generator

A simple and interactive web application built using **HTML, CSS, and JavaScript** that allows users to generate personalized profile cards by entering their details.

## 📌 About the Project

The Profile Card Generator lets users enter their profile picture URL, name, occupation, and a short description. On submitting the form, a profile card is dynamically generated and displayed on the webpage.

This project was created to practise JavaScript events, DOM manipulation, and handling user input.

## ✨ Features

- Add a profile picture using an image URL.
- Enter your name and occupation.
- Add a short personal description.
- Generate a profile card dynamically.
- Simple and clean user interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and layout.
- **JavaScript** – Event handling and DOM manipulation.
